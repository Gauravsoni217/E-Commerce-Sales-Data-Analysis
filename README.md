# E-Commerce Sales Data Analysis

## Objective
Analyze e-commerce sales using Pandas, NumPy, Matplotlib and Seaborn.

## Installation
pip install pandas numpy matplotlib seaborn

## Run
python ecommerce_sales_analysis.py

## Dataset
`ecommerce_sales_raw.csv` contains the raw transaction data. The analysis script cleans it and creates `ecommerce_sales_cleaned.csv`.

## Main results
- Orders analyzed: 600
- Total revenue: ₹1,764,544.40
- Highest-revenue category: Electronics
- Highest-revenue product: Smart Watch
- Highest-revenue month: 2025-04
- Highest-revenue region: West
